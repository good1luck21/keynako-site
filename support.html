Keynako Support / サポート

English

Setup. Install Keynako on both devices. On the iPad: Settings › General › Keyboard › Keyboards › Add New Keyboard… › Keynako, then tap Keynako and turn on Allow Full Access. Open Keynako on the iPhone, tap a text field on the iPad, long-press the globe key and pick Keynako.

The iPad bar says “Looking for iPhone…”. Open the Keynako app on the iPhone and keep it in front. Both devices need Wi‑Fi on; being on the same Wi‑Fi network is the most reliable. If the iPad never finds the iPhone, check Settings › Keynako › Local Network is allowed on both devices.

The iPad connected to the wrong iPhone. Tap the text in the iPad bar to switch to the next iPhone; the choice is remembered.

Return sends instead of adding a line (or the other way round). That is decided by the app you are typing into, exactly as with the iPad's own keyboard. Some apps have a setting for it (LINE: Settings › Chats › Send with Enter).

Password fields show the normal keyboard. iPadOS never allows third-party keyboards in secure fields.

Contact: good1luck21@gmail.com — or use “Send feedback” in the app's settings.

日本語

設定。 iPhone と iPad の両方に Keynako を入れます。iPad の 設定 › 一般 › キーボード › キーボード › 新しいキーボードを追加… › Keynako を選び、一覧の Keynako をタップして「フルアクセスを許可」をオン。iPhone で Keynako を開き、iPad の入力欄をタップして地球儀キーを長押しし、Keynako を選びます。

iPad の帯が「iPhone を探しています…」のまま。 iPhone で Keynako を開いて前面にしてください。両方の端末で Wi‑Fi をオンにし、同じ Wi‑Fi につなぐのが最も確実です。それでも見つからない場合は、両端末の 設定 › Keynako › ローカルネットワーク が許可されているか確認してください。

違う iPhone につながった。 iPad の帯の文字をタップすると次の iPhone に切り替わります。選んだ相手は記憶されます。

Return で送信されてしまう(または改行になる)。 それは入力先のアプリの設定で決まります。iPad 標準のキーボードで打つときと同じ挙動です。アプリによっては設定があります(LINE: 設定 › トーク › 改行キーで送信)。

パスワード欄で標準キーボードが出る。 iPadOS はパスワード欄で他社製キーボードを許可していません。

連絡先: good1luck21@gmail.com、またはアプリの設定にある「フィードバックを送る」からどうぞ。
